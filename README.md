MLP Iris

A simple MLP built from scratch using Python and NumPy.

Features
- MLP implemented from scratch
- Forward propagation
- Backpropagation
- Gradient descent
- Mean Squared Error (MSE) loss function
- Sigmoid activation function
- Dataset

The model is trained on the Iris dataset, which contains 150 samples belonging to 3 classes:
- Setosa
- Versicolor
- Virginica

Each sample has 4 input features:
- Sepal length
- Sepal width
- Petal length
- Petal width
